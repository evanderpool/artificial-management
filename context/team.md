# Team

**Status:** Solo founder/operator — Erick Vanderpool handles strategy, data, automation, content, visual design, and AI engineering.

**Communication hub:** Google Workspace (Drive, Docs, Sheets, Gmail, Calendar)

## Core Pain Point

The biggest operational challenge is not people management — it is **system memory, project visibility, and operational consistency**. The system needs one reliable source of truth that answers:

- What did we already build?
- What are we building next?
- What changed recently?
- What files, agents, prompts, and workflows are current?
- What still needs to be documented?
- What is outdated or no longer true?

## First "Team" = AI Agents

Until human team members are added, the operating team is made of AI agents:

| Agent | Role |
|---|---|
| Chief of Staff Agent | Keeps the whole system aligned |
| Project Manager Agent | Tracks what is being built |
| Documentation Agent | Keeps everything written and organized |
| Data Integrity Agent | Checks consistency and reduces hallucination |
| Portfolio Agent | Turns work into resume and client-facing proof |
| Operations Agent | Manages workflows, SOPs, and recurring processes |

**Rule:** Structure the AI system as if building a company with departments — because that is exactly what is happening.
