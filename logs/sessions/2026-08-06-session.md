# Part 4 — Verifiable citations (Erick: "why can I not click on the sources")

Erick used Ask AI, got cited answers, and asked why the citations weren't
clickable. Correct catch and a real gap: citations named sources without any
way to open them, and the citations I had written were prose labels
("p. 21-22") rather than index coordinates, so they could not have anchored
even with a viewer.

## Built (uplink commit 6f6f832, pushed)
- `GET /api/doc?path=&collection=&seq=&start=&limit=` — serves a window of a
  document's chunks FROM THE INDEX (exact parameterized lookup), never the
  filesystem: no file-read surface to traverse, and it shows exactly what
  retrieval saw.
- Source panel in the web UI: citation chips and search-result paths are
  buttons; the cited chunk is centred and highlighted; earlier/later page
  through the whole document; close button; cleared on a new search.
- AGENT.md: citations MUST be index coordinates (path/section/seq/collection)
  copied verbatim from search JSON.

## Adversarial review of the doc surface — 5 findings, all fixed + pinned
1. HIGH: backward paging passed an absolute offset into `seq`, so the server
   re-centred and silently skipped limit/2 chunks per click (verified: 32-35,
   19-22, 9 unreachable on a 60-chunk doc). Now pages with explicit `start`;
   pinned by a test that walks a whole document and asserts zero gaps.
2. HIGH: a path in two collections resolved alphabetically — showing one
   collection's text as the source of a claim about another. Now 409 with the
   candidate collections (the only case where the feature could manufacture
   false evidence).
3. MEDIUM: citation without `seq` highlighted chunk #0 as "the cited passage"
   (Number(null)===0). Guarded with Number.isInteger.
4. MEDIUM: `seq` beyond int64 reached the SQLite bind → 500 + traceback.
5. LOW-MED: /api/doc returns untruncated text but wasn't logged. Reads now
   join searches in the query log, and the security posture docstring states

## Pass 1 — credibility (commit 54bc49a, 262 tests)

- Answer metrics: count, median time-to-answer, citations/answer,
  ungrounded answers, save rate, and verification rate — first reading

  document the answer cited.

  right-aligned with tabular figures.
- Tooltips on every metric label: definition, how computed, and THE COMMAND

## Pass 2 — self-improvement (commit e458747, 268 tests)
- Retrieval-gaps card: zero-hit queries ranked by frequency, click to re-run.
- **Unknown-term detector**: failed queries split into terms, each tested

  "paid time off". Deterministic SQL, no model.
