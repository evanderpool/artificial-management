# Session Log — 2026-08-06 — Uplink: design, V1, reports, web app

## What happened

Full lifecycle of the new Uplink project in one session: design conversation
-> registration -> V1 build -> adversarial reviews -> publication -> report
phase -> web app. All code in the standalone public repo
github.com/evanderpool/uplink (local: `Desktop/uplink`); this repo carries
only registration, tracker, and logs.

### Design (conversation, two review agents consulted)
- Uplink = local, private, self-hosted RAG. Claude Code is the generation
  layer (no Ollama, no local LLM, no new cost). Sell "private," not "free."
- Architecture review confirmed: Anthropic has no embeddings API -> local
  index layer required. BM25 (SQLite FTS5) first; vectors (fastembed +
  bge-small-en-v1.5) deferred to eval-gated phase 2. ChromaDB rejected
  (Windows MSVC failures); LanceDB is the fallback. Retrieval is a CLI, not
  a daemon; search connections open the DB read-only (mode=ro).
- Separate project from AI OS v2 canonical store. Name: Uplink.
