### Design (conversation, two review agents consulted)
- Uplink = local, private, self-hosted RAG. Claude Code is the generation
  layer (no Ollama, no local LLM, no new cost). Sell "private," not "free."

  bge-small-en-v1.5) deferred to eval-gated phase 2. ChromaDB rejected
  (Windows MSVC failures); LanceDB is the fallback. Retrieval is a CLI, not
  a daemon; search connections open the DB read-only (mode=ro).
- Separate project from AI OS v2 canonical store. Name: Uplink.

# Part 2 — Uplink v0.2: collections, gated writes, industry corpora, feedback loop

## What happened

Erick answered the three open decisions (all recommended options: localhost-
only writes; SEC/NIST/CDC industry corpora — plus an unnamed "Other" slot
left open; collections-in-one-DB / per-client-DBs) and said "start the next
part." Full v0.2 built, twice adversarially reviewed, published same day.

### Shipped (uplink commit 3025270, pushed)
1. **Collections (schema v2):** `documents.collection`, UNIQUE(collection,
   path), per-collection corpus roots, scoped purges, in-place v1→v2
   migration (`uplink upgrade`, chunk ids + FTS preserved, idempotent).
   Default DB moved to `data/uplink.db`; `data/index.db` stays untouched as
   the eval regression corpus (fixtures depend on it) — EA docs are out of
   the web app.
2. **Localhost-only write rule:** upload + thumbs endpoints exist only on a
   loopback bind; wider binds are ask-only by construction. Hardened after
   review: X-Uplink header + Origin check (CSRF), Host validation with
   IP-literal allowance (DNS rebinding), negative Content-Length rejection,
   write serialization, byte-exact multipart parsing, upload overwrite
   refusal + cleanup on failed index.
3. **Industry corpora:** scripts/fetch_corpora.py (public-domain SEC 10-Ks /
   NIST pubs / CDC guidelines; corpora/ gitignored; SEC needs --contact at
   runtime — never committed). Indexed as finance/health/tech: 10 docs,
   4,661 chunks. New fixtures/industry-golden.jsonl (13 q):
   **hit@1 92% / MRR 0.923**, one vocabulary-mismatch miss, logged to eval
   history.
4. **Feedback loop:** query log with latency (data/query-log.jsonl), thumbs
   votes validated against the index (data/feedback.jsonl), `uplink promote`
   (last-vote-wins, idempotent) grows fixtures from real usage; `uplink
   export` emits docs+chunks JSONL (the future Supabase/vector path).

### Reviews (sequential, per protocol)
- **Logic review: 10 findings** — CRITICAL live CSRF corpus poisoning, DNS
  rebinding exfiltration, cap bypass via negative Content-Length, feedback
  forgery inflating eval numbers, multipart content corruption, promote
  ignoring retracted votes, eval-history provenance mixing, and more.
- **Code review: 8 findings** — write-lock contention, Host allowlist
  breaking wide binds + IPv6 bind failure, uncaught sqlite3.Error in CLI,
  snippet delimiter collision with Markdown brackets (now U+0001/U+0002),
  torn-line intolerance in history reader, error misattribution deleting
  good uploads, silent promote success on missing file, fetch IncompleteRead.
- All 18 fixed and pinned. **109 tests passing.** Regression corpus intact:
  hit@1 67% / hit@5 89% / MRR 0.769.
