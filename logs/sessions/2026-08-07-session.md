## What Got Done

- **Native legacy Excel (`.xls`) support** — Erick's upload of 11 EDGAR `.xls` files was refused ("unsupported type"). Rather than converting files, added `_extract_xls` via `xlrd` following the existing optional-dependency pattern: one section per sheet, row caps, integer-float cleanup, encrypted-workbook degradation. Test fixture is a hand-built BIFF2 byte stream (no xls-writing dependency, matching the conftest's hand-built PDF). Packaging: `pip install .[xls]`. Committed by the parallel session as `246d5ab` with an added drift test (SUPPORTED_EXTENSIONS ⊆ CONTENT_TYPES).
- **Apple SEC 10-K corpus** — identified 10 GUID-named EDGAR exports as Apple 10-Ks FY2016–FY2025 (11th file was a duplicate), renamed meaningfully, placed in `corpora/apple-products/sec-filings/`, re-indexed: 10 docs, 728 chunks, 0 errors. The upload dialog's refusal was Uplink working as designed — folder-bound collections take files via folder + re-index, not web upload.
- **Sources panel: search + type filter** — find-as-you-type across label/filename/path (all words, any order) plus per-file-type chips with counts. Filter narrows the visible list only; selection state of hidden rows is preserved; select-all governs visible rows ("All shown").
- **Selection-flow bug found & fixed** — verifying Erick's concern ("answers only from selected sources"): the select-all checkbox rebuilt the selection keyed by bare `path` while everything else keys `collection/path`, so toggle-then-uncheck-one silently searched everything. Fixed with `setAllSelected` keyed by `docKey`; regression test added. Server-side enforcement (scoped docs travel with asks; `GroundingError` on off-scope citations) confirmed intact.
- **Studio relabeled to plain English** — "first answer correct", "ranking quality", "confidence range", "typical search time", "searches with no results", "Library health", etc.; the industry terms (hit@1, MRR, p95) moved into tooltip titles so the panel reads professionally without losing technical credibility.
- **Speech-to-text on the question box** — mic button using the browser's Web Speech API; feature-detected (hidden where unsupported), appends to typed text, live interim results. First version's generic error ("could not hear that") hid four distinct failures; each error code now names itself (silence/wrong device, blocked mic, unreachable speech service, unsupported language). Tooltip honestly discloses that spoken audio transits the browser's speech service — the corpus never does. Working in Chrome after the fix.
- **First full loop on real data** — Erick dictated "performance and profitability of Apple within the last 5 years"; drained from the ask queue by hand: FY2021–FY2025 income statements retrieved from the `.xls` filings, answer with 5 verified citations (net sales, margins, the FY2024 tax-provision dip, EPS vs. buyback story). Files that were unsupported at breakfast were answering dictated questions by evening.
- **Metrics verified + baseline logged** — Studio confirmed live-updating (answers 20, health 257 docs / 10,261 chunks, live re-score matches baseline). Post-ingest eval logged: 90% / 0.900 MRR over 10 questions (`local-apple-golden.jsonl`), unchanged by the 10-K ingest; pre-existing miss "Force Touch trackpad" remains the known gap.
- Uplink commit this session: `b2cb01f` (sources filter + Studio relabel + dictation + eval log). 332 tests.
