## Post

5 weeks ago I started building an AI operating system from scratch.

No team. No funding. Just a clear problem:

AI tools are powerful in isolation — but there's no enterprise-grade system that makes them work *together*. Same data. Same formats. Outputs that feed each other. No lost context between sessions.

So I built one.

**What I built:**

→ 10 specialized AI agents — Chief of Staff, Project Manager, Documentation, Data Integrity, Change Management, Cost Tracking, and more

→ 8 production workflows — each reads from a shared source of truth and writes structured outputs back into the system

→ A weekly executive briefing that runs automatically every Friday, reads from GitHub, and delivers a formatted 8-section summary to the Artificial Management inbox — zero manual work

→ A data integrity engine that audits 52 documents, scores each one 0–100 for consistency, and flags conflicts before they cause downstream problems

→ An append-only decision log and change log — 90+ decisions and 170+ system changes tracked since day one

The system runs like a real company. Departments. Agents. Formal specs. Data flows. SOPs. Audit trails.

Built with Claude Code, 6 MCP server integrations (Gmail, Google Calendar, Google Drive, GitHub, Filesystem, Microsoft 365), and the Anthropic API.

---

This is both a portfolio project and a real service.

Small and mid-size businesses need this kind of operational infrastructure — they just can't afford a full operations team to build it.

That's what Artificial Management is for.

Full README + architecture diagram on GitHub → [github.com/evanderpool]
